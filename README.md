## Repository의 브랜치 역할
- ReadMe: 현 repo의 메인 브랜치로 ReadMe를 주로 수정함.
- main: 실질적 개발에 활용하는 브랜치로 fork 뜬 repo에 pull request를 요청할 수 있음.
- 그외: projects의 마일스톤을 적절히 활용하여, 생성하고 닫고 할 예정

## 브랜치 권한
